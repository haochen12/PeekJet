## 调整面板

右键托盘，或在面板渐亮后右键面板，即可打开设置。更改即时生效并自动保存。

| 设置 | 选项 |
| --- | --- |
| 外观主题 | 午夜深色、云白浅色、深海青蓝、暖砂琥珀、跟随系统 |
| 预览大小 | 80 / 100 / 120 / 160 逻辑像素，默认 100 |
| 悬停激活时间 | 默认 150ms；常用预设及 50–2000ms 自定义 |
| 停靠边缘 | 默认顶部；支持上下横排、左右竖排和拖拽吸附 |
| 显示位置 | 跟随当前 VS Code，或固定到指定显示器 |
| 输入时自动避让 | 默认开启，可在菜单关闭 |

跨屏拖动后会固定到目标屏；可从菜单恢复自动跟随。每页最多 10 个预览，空间不足时提前分页。当前正在使用的窗口预览会淡化，点击其他项目可切换，最小化的窗口也可通过预览恢复。

## 显示与隐藏

- 多窗口时面板常驻，切换后继续显示；只剩一个或全部关闭时自动隐藏。
- `Ctrl + Alt + V` 或单击托盘可显示、隐藏或唤回面板。
- 打字时，如果 VS Code 与面板重叠，面板会完全透明并保持穿透；停打约 1.2 秒后在原位置恢复。
- 右侧按钮最小化所有预览页的 VS Code 窗口，面板仍可用于恢复窗口。

## 常见问题

**没有出现预览？** 确认有至少两个 VS Code / Insiders 窗口，尝试快捷键唤回，或在托盘菜单中刷新窗口。

**最小化后的预览不更新？** Windows 可能保留缓存画面，恢复窗口后继续实时更新。

**项目名不准确？** 项目名依赖标准 VS Code 窗口标题，自定义标题格式可能影响识别。

**部分窗口没有列出或无法切换？** 其他虚拟桌面上被系统隐藏的窗口不会列入预览；Windows 可能限制切换到管理员权限的 VS Code。

**如何升级或卸载？** 退出旧版后替换程序，设置保留。卸载时退出并删除程序目录即可。

## 隐私、设置与日志

程序不联网、不遥测、不录屏，实时预览由 Windows DWM 合成。输入避让只保留事件时间和前台窗口句柄，不读取或保存键值与输入文本。

- 设置：`HKEY_CURRENT_USER\Software\PeekJet`，兼容读取旧版 VSCodePreview 设置。
- 日志：`%LOCALAPPDATA%\PeekJet\error.log`。
- 程序不会自动设置开机启动。需要完全清理时，可在退出后手动移除上述设置与日志。

下载页中，`windows.zip` 为便携程序，`source.zip` 为源码，`SHA256SUMS.txt` 为校验文件。文档描述 main 分支，已发布功能请查看 [更新日志](../CHANGELOG.md)。
